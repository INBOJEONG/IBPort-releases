Extract the manual ZIP and choose a language in README. Authenticate and start your own CLIs, then select one Master and the Workers in local PowerShell or SSH terminals.

Windows previews are unsigned. macOS packages have ad-hoc signing only, without Developer ID signing or Apple notarization. Native macOS GUI checks used a disposable mock Keychain; interactive real-Keychain consent and encryption remain separately unverified. Embedded RDP is Windows-only. Package checks do not establish successful installation/upgrades or every live model/RDP workflow. See the release notes for exact validation scope.
