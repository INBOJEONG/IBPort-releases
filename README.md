# IBPort

**by IBLabs** · **IBPort — 통합 원격 접속 도구**

**서버 연결과 작업을 한곳에서.**

압축 설명서는 README에서 언어를 선택합니다. CLI 로그인·실행은 사용자가 진행하며, 로컬 PowerShell 또는 SSH 터미널에 Master 한 개와 Worker들을 지정합니다.

Windows 프리뷰는 서명되지 않았습니다. macOS는 ad-hoc 서명이며 Developer ID 서명·Apple 공증이 없습니다. macOS 네이티브 GUI 검사는 일회용 모의 Keychain을 사용했으며 실제 사용자 Keychain 승인·암호화는 별도 검증이 필요합니다. 내장 RDP는 Windows 전용입니다. 설치·업그레이드와 모든 실제 모델·RDP 작업의 성공을 보장하는 검사는 아닙니다. 자세한 확인 범위는 릴리스 안내를 참고하세요.
